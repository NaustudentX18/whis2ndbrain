Meet Pip, the thoughtkeeper.

Every good tool has a face. Whis2ndBrain’s is a small memory moth who carries one glowing spark at a time — the shape of the job: catch a thought, keep it safe, hand it back when you ask.

  • Pip is not a wake word. Nothing listens until you physically hold the button.
  • Pip is not always-on. Ambient mode is a clock and a battery gauge — a quiet companion, not a microphone.
  • Pip is not an agent. No suggestions silently become truth, and nothing acts on your behalf. Machine help stays labelled, editable, and allowed to say “not sure”.
  • Your recordings are yours. Kept on your hardware, held under an explicit retention policy, exported only when you say so.

Scope, host, security, retention and privacy policy decided and recorded; the project adopted Apache-2.0; performance targets set for measurement. Hardware commissioning is formally open.

Adversarial hardening and honest rehearsals

A crash-boundary and hostile-upload test matrix (tombstone replay, killed workers, export atomicity, symlink refusal), bounded offline behaviour for the browser client, an automated accessibility pass, a real-model latency harness, and a scripted clean-host install rehearsal that proves the documented path from the repository alone.

Sep 30

One honest deploy

The documented single-owner deployment runs the latest reviewed code as a supervised service behind a private TLS origin, live-verified end to end on synthetic data: pair a device, upload, receipt, transcription, byte-range audio, trash and restore.

Sep 29

Security and robustness hardening pass

Isolated, killable transcription with manual retry; pair-once device credentials and owner sessions with CSRF and rate limiting; byte-range audio with tombstones and edit-conflict protection; hardened deterministic export; owner-only metrics; manifest backup with fail-closed restore rehearsal. One browser client chosen and built to full parity.

Sep 28

Continuous integration is live and green

GitHub Actions runs the Python unit suite and lint plus the Flutter analyze, test and debug-APK build on every push. Both pipelines pass.

Sep 27

Bounded host prototype published

Receipt-guarded ingest with deduplication, bounded validation, a transcription job queue, an owner-correction review shell and conflict-safe Markdown export — covered by unit, integration and a desktop-Chromium test.
