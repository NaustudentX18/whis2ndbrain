# Brand assets

An original, early identity for Whis2ndBrain. The open loop and central spark mean “a thought safely kept”; **Pip** is the friendly memory-moth companion, not an always-listening assistant.

- `mark.svg` — standalone loop-and-spark icon.
- `wordmark.svg` — authored vector logotype + tagline; keep as the source of truth for the brand lettering.
- `pip-hero.png` — new transparent, soft 3D Pip illustration used in the README, landing page and proposed device-screen concept. Generated with OpenAI's built-in image generation from an original project prompt; no external character reference was supplied.
- `pip-mascot.svg` — earlier original vector Pip concept, retained as an editable/scalable alternative rather than silently replaced.

## Palette

| Token | Hex | Intent |
| --- | --- | --- |
| Night | `#101A1D` | Quiet evergreen-charcoal canvas |
| Panel | `#1C2A2B` | Raised surface |
| Mist | `#F1F4E9` | Primary text |
| Sage | `#ADBBB1` | Supporting text |
| Pip mint | `#BDF4D7` | Positive/active accent, never the only status signal |
| Signal lilac | `#C4B6FF` | Secondary glow / companion accent |

The vector wordmark is custom artwork rather than an installable typeface. The page uses system font stacks; no web-font download, license or loading dependency is present. Keep the mascot's role warm and quiet. Never use the character or color alone to convey recording, privacy, battery or error state. The PNG is concept artwork, not an optimized device framebuffer or proof of a working display.
